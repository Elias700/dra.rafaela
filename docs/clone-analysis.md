## 2. Constantes globais de movimento

```js
breakPoint = 992        // desktop ≥ 992px
durS = 0.4  durM = 0.8  durL = 1.2

```

| Easing (CustomEase) | Bezier               | Uso no clone                      | Projeto                          |
| ------------------- | -------------------- | --------------------------------- | -------------------------------- |
| `Out`               | `0.25, 1, 0.5, 1`    | quase todos os reveals            | **easing padrão** (já é suave)   |
| `InOut`             | `0.75, 0, 0.25, 1`   | máscaras, slides, menu            | suavizar para `0.65, 0, 0.35, 1` |
| `In`                | `0.5, 0, 0.75, 0`    | saídas/hides                      | manter (só saídas)               |
| `Ease`              | `0.25, 0.1, 0.25, 1` | hover de nav, snap                | manter                           |
| `diveIn`            | `0.6, 0, 0, 1`       | “mergulho” do preloader           | usar na intro do hero, encurtada |
| `horScroll`         | `0.25, 0, 0.75, 1`   | scroll horizontal                 | manter                           |
| `Write`             | `0.333, 0, 0.667, 1` | não usado na home                 | —                                |
| `loaderEase`        | path com 5 segmentos | barra de progresso do loader (4s) | ❌ sem loader com barra          |

**Lenis global:** `duration: 1.2`, `easing: t => min(1, 1.001 − 2^(−10t))` (expo-out), `smoothWheel: true`, `touchMultiplier: 2`, acoplado ao `gsap.ticker` com `lagSmoothing(0)` e `lenis.on('scroll', ScrollTrigger.update)`.
**Outros globais:** `--_100svh` fixado em px no load; `ScrollTrigger.refresh(true)` com debounce de 40ms no resize; `history.scrollRestoration = 'manual'`.

**Ajuste de tom para o consultório:** manter `durL = 1.2` e `Out`; reduzir distâncias (x/y) e rotações 3D pela metade ou mais; nenhum `scale` acima de ~1.15 em zooms de scroll.

### 3.2 Reveals de texto e blocos (o “vocabulário” do site)

Todos são disparados por `ScrollTrigger.create({ trigger, start: 'top bottom', once: true })`, agrupados pelo wrapper `[data-scroll-reveal="w"]` (itens do mesmo wrapper entram juntos com `stagger`). Estado inicial aplicado via JS (`'initial'`) — o conteúdo só fica escondido depois que o JS roda (bom para SSR). Cada função tem modos `reveal` / `hide` / `initial`, reutilizados em hovers, sliders, tabs e menu.

## 4. Mapeamento animação → seção → diretiva

Ordem das seções conforme o prompt, com um ajuste: **“Por que escolher a clínica” antes de “Implantes”** é uma opção, mas mantive a ordem sugerida e uso a “janela que se abre” (A16) como transição de Tratamentos → Implantes, para que as duas seções com sticky (Tratamentos horizontal e Implantes) não fiquem coladas sem respiro: a janela funciona como respiro visual entre elas.

## 6. Notas da implementação (Fases 1–4)

Ajustes feitos durante a construção, em relação ao plano acima:

- **Intro do hero (A1/A2/A3)**: implementada em **CSS puro** (`hero.scss`, classe `html.intro-pending` aplicada pelo script inline do `index.html`, 1x por sessão). A frase já vem separada em palavras no HTML do SSR. Frase e subtítulo animam só com movimento (sem fade) para não atrasar o LCP.
- **Inicialização adiada**: GSAP/ScrollTrigger/SplitText/Lenis são importados dinamicamente e só iniciam na **primeira interação** (scroll, toque, tecla, ponteiro) ou 7s após o `load`. Nada pesado compete com o carregamento.
- **Títulos (A4)**: por palavra com máscara (no clone: letras com rotateY).
- **Janela em arco (A16)**: o recorte em arco é estático (CSS) e só as folhas se movem (`transform`); o título aparece dentro do arco antes de as folhas se abrirem.
- **Hidratação incremental**: todas as seções abaixo do hero, o rodapé e o botão flutuante usam `@defer (hydrate on idle)` — HTML completo no prerender, JS carregado depois.
- **Estados iniciais sem opacidade parcial** (só visível/escondido) para não gerar falsos problemas de contraste.
